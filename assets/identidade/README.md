# Assets de marca RYVO

Cada arquivo nesta pasta é um asset independente, pronto para referenciar pelo front.

- `ryvo-logo.svg`: logo horizontal com símbolo e nome.
- `ryvo-logo-tagline.svg`: logo com a assinatura “Seu espaço. Sua galera.”.
- `ryvo-symbol.svg`: símbolo isolado.
- `ryvo-wordmark.svg`: nome RYVO isolado.
- `ryvo-logo-white.svg` e `ryvo-symbol-white.svg`: versões monocromáticas.
- `ryvo-app-icon.svg` e `ryvo-app-icon.png`: ícone do app.
- `favicon.svg`, `favicon.ico` e `favicon-*.png`: ícones da aba.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` e `icon-maskable-512.png`: exports de instalação.
- `assets.json`: catálogo de caminhos.
- `preview.html`: prévia dos arquivos individuais.

Os logos e o símbolo são transparentes. Os SVGs com texto incluem Figtree embutida. A paleta é a de `docs/identidade.md`.

Veja o [guia de integração](../../docs/identidade/assets.md) para dimensões e exemplos de HTML.
